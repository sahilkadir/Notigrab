\# Changelog



All notable changes to NotiGrab are documented here.



\## \[2.0.0] - 2026-08-14



\### Added



\- Added app selection for notification capture.

\- Added searchable installed-app list.

\- Added account-based favorite notifications.

\- Added app-specific favorite accounts.

\- Added profile/avatar support.

\- Added favorite-first notification ordering.

\- Added swipe-to-delete notifications.

\- Added Clear All functionality.

\- Added automatic 48-hour cleanup for normal unsaved notifications.

\- Added custom app icon.

\- Added opening animation.



\### Improved



\- Improved Inbox and Saved notification separation.

\- Improved notification card UI.

\- Improved dark-mode readability.

\- Improved app selection and search.

\- Improved favorite notification handling.

\- Improved notification persistence and refresh behavior.



\### Fixed



\- Fixed saved notifications appearing in Inbox.

\- Fixed notification search/input issues.

\- Fixed Clear All so saved notifications are protected.

\- Fixed Clear All so favorite notifications are protected.

\- Fixed automatic cleanup so favorite notifications are protected.



\## \[1.0.0]



\### Initial Release



\- Initial NotiGrab Android application.

\- Notification capture using Android NotificationListenerService.

\- Local notification storage.

\- Basic notification management.

\- Saved notification support.
